# Whether virtue can itself be defiled?

## Bibliography

<!-- 

Notes:

The question is, is virtue itself something that, existing in a positive sense, is capable of being defiled, or rather is virtue "defiled" to the extent that a person lacks virtue (i.e., "So and so's virtue is soiled.")? In the latter case, it is not as if one possesses virtue as a thing which is defiled in some way, but they lack the virtue, which in this example is just the conduct itself, say, in the first place.

If virtue is considered to be an actual thing, then is it defiled intrinsically or extrinsically, if at all? For instance, we might say water is polluted by dirt; however, strictly speaking, the H20 remains pure H20, but the water as the combination of the H20 and pollutants is polluted. This seems to be extrinsic pollution. However, some changes alter something intrinsically, as when bread is toasted, it undergoes chemical changes.

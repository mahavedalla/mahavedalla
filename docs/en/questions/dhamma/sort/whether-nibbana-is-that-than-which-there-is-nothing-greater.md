# Whether Nibbāna is that than which there is nothing greater?

## Bibliography

<!-- 

Notes:

SNP 1099: "yathāyidaṃ nāparaṃ siyā". SNP 1101: "etaṃ dīpaṃ anāparaṃ". This bears notable resemblances to Anselmian perfect being theology: i.e., God is that (being?) than which there is nothing greater. Traditionally, Nibbāna itself is not taken to be personal. Is Nibbāna the state than which there is nothing greater? Granted, this is verse aimed at poetic effect. If one were to construct a doctrine of Nibbāna from the concept of a perfect state than which there is nothing greater, how would this affect certain views? Could the mere destruction of the defilements be that than which there is nothing greater? If not, can it be living beings' ultimate end?
